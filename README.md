# FairPlayTime Flutter App

FairPlayTime is a Flutter-based mobile application designed to assist soccer coaches and teams in managing match preparations, lineups, game setups, and player histories. The app features a clean, modern UI with green accents, providing an intuitive experience for team management and analytics.

## Features

- **Splash Screen:** Engaging introduction with the app logo and tagline.
- **Onboarding:** Step-by-step guide highlighting key features (Easy Coaching, Smart Substitutions).
- **Authentication:** Login, Sign Up, and Forgot Password flows with OTP verification.
- **Team Profile:** Input club and team details, upload logo, and add coach and player information.
- **Plan Selection:** Choose from Basic, Basic+, Premium, or Pro plans with monthly/yearly pricing options and feature highlights (e.g., Fairness Calculator, Squad Analytics).
- **Payment Method:** Add credit/debit card details and select payment options.
- **Home:** View next match preparation, equal playing time calculator, and manage lineup/game setup.
- **Lineup Management:** Add and manage team players, set positions, and save changes.
- **Games:** View previous, next, and add new matches with opponent details.
- **Live Match:** Real-time match data, player lineup, and action updates.
- **Player History:** Detailed stats and match history for individual players.
- **Settings:** General settings, privacy, security, data collection, and terms & conditions.

## Usage
- Sign up or log in to access team management features.
- Set up your team profile and select a subscription plan.
